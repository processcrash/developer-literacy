# aipw — AI Personal Workbench

HTML 原型（单文件，无依赖）。用浏览器直接打开 `index.html` 即可。

## 原型 V3 里能玩什么

- **步骤看板**：默认四步「规划 → 实施 → 审查 → 归档」，一排列；每个项目一套自己的步骤（顶部切换项目）。
- **步骤头 ⚙ 设置**：点列头右侧 ⚙，弹框最上面选「人做 / AI 做」；选 AI 做时勾选 Agent（可新建条目）；切回人做时绑定保留但暂不启用。列头单行显示，Agent 标签压缩（列窄时自动省略）。
- **三态视觉**：
  - pending：普通白卡片；
  - doing：**浅蓝底 + 呼吸小圆点**（一眼看出 AI 正在做）；
  - awaiting-decision：红边框 + 淡红底 + 「⚠ 需要人决策」标签 + 轻微呼吸动画，且**置顶**。
- **拖动规则**：只有「人做」步骤的卡片可拖；AI 步骤卡片不可拖（流转自动）；失败卡片靠聊天里【手动重派 / 放弃】按钮。
- **卡片完整信息面板**（点卡片右侧打开）：卡片自身全部内容（标题/级别/项目/描述全文/标记）+ **步骤时间线**——任务经过的每个步骤一段：该步 agent、聊天内容、产出摘要与文件引用；当前步骤高亮默认展开，历史步骤折叠可点开。
- **流程模拟**：pending 自动派发 → 干完自动进下一步骤；「规划」完成触发**收敛单**（回答/合并/丢弃后才进实施）；失败自动重派 3 次；聊天里可「模拟完成/提问/失败」。
- 数据是写死的模拟数据，刷新页面即重置。
